# Web Lab

Web Lab 是一个面向大学一年级学生的纯前端 Web 程序设计交互学习平台。

**Learn · Try · Debug · Create**

## 项目目标

Web Lab 不以阅读教材式内容为主要学习方式，而是通过：

知识学习 → 修改代码 → 实时预览 → 完成任务 → 调试错误 → 完成作品

帮助学生逐步学习 HTML、CSS、页面布局、JavaScript、DOM 和 Web 数据可视化，并最终完成一个能够通过 GitHub Pages 发布的数据项目网页。

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript
- iframe `srcdoc`
- LocalStorage
- Chart.js（建议本地化静态资源）
- GitHub Pages

不使用：React、Vue、Angular、Next.js、Node.js 后端、数据库、用户账号系统。

## 课程模块

0. Web 与开发环境
1. HTML
2. CSS
3. 页面布局与响应式设计
4. JavaScript
5. DOM 与网页交互
6. Web 数据可视化
7. 数据项目网页
8. Final Project

## 核心功能

- 交互式 Lesson
- HTML/CSS/JS 编辑器
- iframe 实时预览
- JavaScript Console
- Challenge 自动检测
- Debug Lab
- CSS Playground
- Box Model Lab
- Flex Playground
- Chart Lab
- 学习进度保存
- 数据导入导出
- 版本演进
- 综合项目
- GitHub Pages 部署

## 本地运行

本项目原则上不依赖构建工具。Clone 仓库后可直接打开 `index.html`，推荐使用 VS Code Live Server。
