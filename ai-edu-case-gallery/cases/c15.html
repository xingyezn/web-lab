版本一 · 本地运行

Python＋SQLite在本机运行，注册和班级资料保存在这台电脑。

  1. 解压现有运行包，双击“启动工作台.cmd”；想做自己的版本时上传需求和模拟名册，复制本地版提示词。
  2. 注册账号，添加学生，登记一天考勤和一次作业；完成待办并导出班级资料。
  3. 重新登录或重启程序，查看记录；用第二个账号检查班级分别保存。

本地运行版提示词

请根据附件制作一个本地运行的班主任工作台，使用Python后端和SQLite数据库，提供Windows双击启动入口和运行说明。 支持教师注册、登录、退出和修改密码，每个教师账号分别管理一个班级。包含学生名册、每日考勤、作业收交与订正、班级待办、家校沟通记录和资料导出。概览显示学生人数、今日到校人数、作业未交人数和未完成待办。注册时可以选择带入8名模拟学生。 数据写入本机数据库，刷新页面、退出后重新登录或重启程序，记录仍在。密码使用带盐散列保存，接口按当前登录账号读取和修改记录。 交付完整运行包，浏览器从本机地址访问；用两个模拟账号检查注册登录、学生录入、考勤、作业、待办和资料导出。

版本二 · 在线应用

WorkBuddy网站应用接入云端登录与数据库，教师用网址管理自己的班级。

  1. 在WorkBuddy新建网站应用任务，上传功能需求与模拟名册，复制在线版提示词。
  2. 按提示开启身份认证与云数据库，完成学生、考勤和作业的试用。
  3. 发布后在手机登录同一账号查看记录，再用第二个账号检查各自的班级。

在线应用版提示词

请根据附件制作一个“班主任工作台”网站应用，使用WorkBuddy的网站应用能力和内置云服务，完成后发布为可在线访问的网址。 使用云服务身份认证实现教师注册、登录、退出和账号管理，按所启用的登录方式提供密码修改或账号找回入口。每位教师可以管理自己的多个班级，同一账号在电脑和手机登录后继续处理同一份班级资料。 包含学生名册、每日考勤、作业收交与订正、班级待办、家校沟通记录和资料导出。概览显示学生人数、今日到校人数、作业未交人数和未完成待办。注册时可以选择带入8名模拟学生。 班级、学生、考勤、作业、待办和沟通记录全部保存在云数据库，不同教师账号分别读取和修改自己的数据。 支持按日期查看考勤、按作业查看未交和待订正名单，导出本周汇总与班级JSON备份。需要开启云服务时引导我完成确认，再完成登录、数据读写和权限配置。使用模拟名册试用，页面适配电脑和手机。 完成后发布网站应用，用实际发布链接检查注册登录、录入保存、换设备读取和账号隔离。交付真实可访问的HTTPS链接，以及更新发布、备份数据的方法。

在线版的发布方法

  1. 在WorkBuddy首页进入“代码开发”，选择“网站开发”或“Agent应用”；也可以直接发送在线版提示词。
  2. 生成后打开网站应用卡片，按提示开启云服务，接入登录和数据库。
  3. 在预览区点击“分享”发布，或发送“发布上线”，获取自己的应用链接。
  4. 用实际链接登录、保存一条模拟记录，再换设备读取。后续修改后发送“更新发布”，同步到原链接。

发布前用模拟资料完成验证。云服务可用额度以当前账号页面为准。

班主任工作台功能需求

账号：注册、登录、退出、修改密码。每位教师看到自己的班级记录。

班级概览：学生人数、今日到校人数、当次作业未交人数、未完成待办。

学生档案：学号、姓名、监护人、联系信息、备注；支持添加、编辑、搜索和删除。

每日考勤：选择日期，按学生登记出勤、迟到、请假、缺勤；可统一标记出勤，再调整个别学生。

作业收交：按学科新建作业，记录截止日期，逐人标记未交、已交、待订正。

班级待办：记下要做的事和计划日期，完成后勾选。

家校沟通：记录学生、日期、沟通方式、内容和后续安排。此处记录沟通，不发送消息。

班级设置：修改班级名称；导出当前账号的班级资料。

本地版：Python＋SQLite在本机运行，每个教师账号管理一个班级，注册时可带入8名模拟学生。

在线版：WorkBuddy网站应用＋云服务身份认证与数据库，每位教师可管理自己的多个班级，同一账号跨设备访问。发布后交付实际访问链接。

两个版本都按教师账号区分数据。学生端、家长端和学校管理员可在后续扩展。

班主任工作台运行说明

这是带真实注册登录和数据库保存的本地运行示例，需要Python 3.10或以上，不需要安装第三方包。

启动

解压运行包，Windows双击“启动工作台.cmd”。也可让WorkBuddy在解压目录运行：

python server.py --open

其他系统可使用 python3 server.py --open。浏览器访问 http://127.0.0.1:8835/ 。如果端口已占用，可运行 python server.py --port 8836 --open。

开始练习

点击注册，填写用户名和至少8位密码。可勾选带入8名模拟学生及示例记录；也可空白开始。注册成功后进入自己的工作台。

试着添加一名学生，为某天登记考勤，新建作业并标记收交，完成一项待办，保存一条沟通记录。刷新页面，检查记录仍在；退出后再次登录。

再注册一个不带模拟数据的账号，检查两个账号分别保存各自记录。账号、密码和数据保存在本机data目录的SQLite数据库中；密码为带随机盐的PBKDF2散列。

文件

- server.py：登录与业务接口、SQLite保存。
- index.html、app.css、app.js：前端界面。
- 启动工作台.cmd：Windows启动入口。
- data：首次运行后生成，包含本机账号与数据，不在下载包中预置。

“导出班级资料”可下载当前班级的JSON文件。本示例提供导出，未实现导入恢复。

在线应用版本

此运行包是本地版，启动后从本机地址访问。需要在线使用时，在案例页选择“版本二 · 在线应用”，复制在线版提示词，使用WorkBuddy网站应用接入云端登录与数据库，再发布获取实际网址。

已有本地数据时，使用“本地版升级在线版提示词”，导出当前班级JSON，再在在线版中导入。本机账号与云端账号分别注册。

已有云服务器的用户，可以追加“已有云服务器部署提示词”，由WorkBuddy适配后端、持久化数据库和HTTPS部署。
