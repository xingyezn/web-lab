# 使用HTML交互式课件技能

在WorkBuddy的“专家·技能·连接器”中进入“技能”，选择“添加技能 → 上传技能”，上传本案例的“HTML交互式课件_Skill.zip”。

新建任务，输入“请调用HTML交互式课件技能”，补上年级与知识点即可。没有决定效果时，让它先问你：翻页讲解、动态演示还是互动闯关。

已有HTML时，上传文件并说明想增加的互动，例如“加入拖拽拼句与即时反馈，保留原来的翻页功能”。

示例：打开“MySchoolDay_交互式课件.html”。左右方向键翻页，目录可以跳转，页面上方可选择切换效果和全屏。时钟、拼句、作息选择和三题小测均可直接操作。

技能包包含SKILL.md、互动选择参考和一份完整HTML模板。模板是本次配套示例，可用作新课件起点。

技能包结构与上传入口依据WorkBuddy官方文档，核查日期2026年10月28日：
